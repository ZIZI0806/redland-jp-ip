# RED LAND 2026 · 日本 IP 展位复盘

上海杨浦复兴岛 RED LAND 2026（2026.10.02–10.06）现场，日本 IP 展位的活动内容与
观众口碑整理。地图上每个热区对应一个展位，点开可看：

- **出展商** —— 出展主体、IP 起源、展位位置；
- **展台活动** —— 官方公布的每项活动 + 一张官方配图；
- **用户体验总结** —— 用户评论数、舆情综述、分主题用户感想、代表性原帖。

## 数据说明

- 展位清单与热区坐标来自社区攻略项目 [zzixxxx/redland-guide](https://github.com/zzixxxx/redland-guide)。
- 活动配图取自各 IP 官方小红书笔记；实拍照片来自到访观众在小红书发布的笔记，
  **版权归原作者所有**，本站仅作整理展示，附原帖链接可回跳核对。
- 「用户评论数」为实际采集到的非作者评论条数，与笔记页显示的评论总数不同。
- 口碑结论按主题归类整理，情绪由词表判定后人工复核；每个主题都给出代表性原话与反面意见。

## 结构
